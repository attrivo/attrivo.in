Google Integration

Attrivo Dashboard — What to Configure

  • Ad Account ID: Account from which your Google campaigns are live
  • Manager Account ID: Google MCC ID of your Sub Accounts
  • Access Token & Refresh Token: Pulled automatically once you "Sign in with Google"

Enable the Cost Integration toggle to receive cost data. Enable Postback Settings to send Install and Event postbacks to your Google Conversion Actions.

Note: Ensure to Save Settings every time you make any change. Otherwise, updated data will not be reflected.
Attrivo Dashboard — SAN Integration (Google)

1. Current Setup — What's Happening Now

Your Google Ads campaigns may be using internal tracking links as Final URLs:

partner_id=iv_web&la_code=PPIV&d_id={'{'}adid{'}'}

Result: Most paid traffic from Web Search campaigns is being reported as Organic.

Root Causes:

  • Auto-tagging may be OFF — so Google never appends gclid
  • No UTM parameters in your ad URLs
  • Internal tracking links do not carry Google attribution signals
  • Some links redirect and strip the gclid before reaching the landing page

2. Recommended Setup

# What Recommended Setup
1 Add Final URL in Ad https://www.example.com/landing-page/
2 Auto-tagging Must be ON
3 Campaign URL Suffix utm_source=google&utm_medium=cpc&utm_campaign={'{'}campaignid{'}'}&utm_term={'{'}keyword{'}'}&utm_content={'{'}creative{'}'}

3. What Changes After Implementation

Scenario Current Setup Recommended Setup
Click Tracking
User clicks Google Ad Goes directly to website with no tracking Lands on destination with UTMs + GCLID attached
Google attribution ❌ Shows as Organic in most cases ✅ Attributed to Google Ads via GCLID
Campaign details visible ❌ Not available ✅ Campaign, keyword, and ad creative level

4. Step-by-Step Implementation Guide

1

Turn ON Auto-tagging in Google Ads

Navigate to:

  1. Google Ads
  2. Admin → Account Settings
  3. Auto-tagging
  4. Toggle to ON
  5. Save
Google Ads — Admin → Account Settings → Auto-tagging
2

Add Campaign URL Suffix

Navigate to:

  1. Google Ads
  2. Campaigns
  3. Click on your Campaign name
  4. Settings
  5. Scroll to 'Campaign URL options'
  6. Final URL suffix field — enter the following:
utm_source=google&utm_medium=cpc&utm_campaign={'{'}campaignid{'}'}&utm_term={'{'}keyword{'}'}&utm_content={'{'}creative{'}'}

Google's dynamic parameters ({'{'}campaignid{'}'}, {'{'}keyword{'}'}, {'{'}creative{'}'}) fill in automatically — no manual updates needed per campaign.

Google Ads — Campaigns → Settings → Campaign URL options

Meta Integration

Attrivo Dashboard — What to Configure

  • Ad Account ID: Account from which your Meta campaigns are live
  • Data Set ID: Facebook Ads → Events Manager → Datasets → Select Dataset ID of App
  • Decryption Key: Developer Account → Select App → Basic Settings → Decryption Key
  • Access Token: Facebook Ads → Events Manager → Datasets → Select Specific Dataset ID → Settings → Generate Access Token
Note: Ensure to Save Settings every time you make any change. Otherwise, updated data will not be reflected.
Attrivo Dashboard — SAN Integration (Meta)
1

Retrieve: Data Set ID

Steps:

  1. Meta Ads Account
  2. Events Manager (Left Menu)
  3. Select Data Sets (App from which campaigns are live)
  4. Select Data Set ID
Meta Ads — Events Manager → Datasets
2

Retrieve: Decryption Key

Steps:

  1. Meta Developer Account
  2. Select App
  3. Go to Basic Settings and scroll down to "Decryption Key"
Meta Developer Account — Basic Settings → Decryption Key
3

Retrieve: Access Token

Steps:

  1. Meta Ads Account
  2. Events Manager (Left Menu)
  3. Select Data Set ID (App from which campaigns are live)
  4. Select Settings tab
  5. Scroll down and click "Generate access token"
Meta Events Manager — Dataset Settings → Generate Access Token
